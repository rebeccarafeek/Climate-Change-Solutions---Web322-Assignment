# 🌱Climate Solutions Website

Final project for Web322 course - a web application for managing climate change solutions with full CRUD functionality.

🌍 **[Live Demo](https://web322-a5-roan.vercel.app)**

## ✨Features

- Browse, add, edit, and delete climate solutions
- RESTful API implementation
- Responsive design with Tailwind CSS
- PostgreSQL database management (via pgAdmin)  
- Deployed on Vercel

## 🛠Technologies

- Node.js/Express.js
- Tailwind CSS
- RESTful API
- PostgreSQL (managed with pgAdmin) 
- Vercel deployment
